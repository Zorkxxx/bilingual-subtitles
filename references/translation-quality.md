# 多语翻译与译义复核

以实际原文为依据，结合前后对白、画面、说话者及人物关系，按场景翻译成自然的简体中文。片段边界需要带上相邻上下文；混合语言分别确认原语。原文或关系不确定时保留歧义，不猜测人称、性别、指代或情节。

- 逐句保留动作、对象、因果、条件、否定、数量、时间和人物态度等实际含义；自然压缩表达时不能删掉关键信息或增加原文没有的事实。姓名、称谓和术语查询作品级 glossary，并在适用范围内保持一致；同词不同义或关系变化时结合语境调整，不做机械替换。
- 日语、韩语特别留意敬语、称谓及省略的主语，不能凭空补出确定对象；德语留意分离动词、否定和情态，法语留意否定、语体及人称形式。各语言都结合上下文处理语气、口语和多义表达，不把语言特征套成固定译法。
- 初译后自行另做第二轮译义复核：对照来源原文与译文及前后语境，按来源 ID 逐项检查漏译、误译、增译、否定与数字、指代、称谓、语气和术语。可由同一模型分轮执行，不能因此声称独立模型或人工审校。对白与画面文字都要检查；拆分或合并的条目按来源与目标的多对多对应检查全部含义，不以条数或时间重合作为完整证明。发现问题后修正，并重新核对受影响内容及上下文。
- 对无法判断的原文或译法记录时间、候选、原因及现有证据，标为待核；不要为凑完整而编造或标记已验证。译文对照可以依据已有原文执行，但它不证明原文与音画一致；听辨和画面状态仍须对应实际可用证据。格式、覆盖台账及模型一致也不能证明语义正确。
